# موقع برانكا

موقع تعريفي ثنائي اللغة (العربية والإنجليزية) يدعم الوضعين الفاتح والداكن، ومهيأ للنشر على Vercel.

## قبل النشر

1. انسخ ملف `.env.example` باسم `.env.local`.
2. إنستغرام مربوط بالمعرف `i_dd_m`، وتم اعتماد المعرف نفسه مؤقتًا لحساب إكس لأن الرابطين المرسلين كانا متطابقين. يمكن تغييرهما بمتغيرات البيئة.
3. يمكن توسيع أقسام المتاجر والموشن بأعمال إضافية لاحقًا.
4. تُعرض الحملات كمشاريع شارك إبراهيم في إدارتها وتنفيذها ضمن فريق دون ذكر أسماء أعضاء الفريق.
5. تأكد من موافقة أصحاب النتائج والعملاء على نشر صور لوحات الأداء والأرقام.

صورة إبراهيم، جميع أعمال الجرافيكس، وأربع دراسات حملات بأرقامها وصورها، وثلاثة تصاميم متاجر إلكترونية، وتسعة فيديوهات موشن مضافة بالفعل داخل الموقع.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الرابط المحلي الذي يظهر في نافذة الأوامر.

## النشر على Vercel

ارفع المشروع إلى GitHub ثم استورده في Vercel. أضف متغيرات التواصل الموجودة في `.env.example` داخل إعدادات المشروع قبل النشر النهائي.

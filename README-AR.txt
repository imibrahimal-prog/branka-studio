تحديث لمعة خطوط شاشة التحميل

يضيف هذا التحديث لمعة ذهبية بارزة تمر على الخطوط الجانبية اليمنى واليسرى أثناء التحميل.
لا يغيّر شكل الصفحة أو ألوانها أو أي قسم آخر في الموقع.

طريقة الاستخدام:
1. انسخ جميع محتويات هذا المجلد إلى داخل مجلد branka-studio.
2. شغّل apply-update.cmd بالنقر المزدوج.
3. افتح GitHub Desktop.
4. اكتب في Summary: إضافة لمعة متحركة لشاشة التحميل
5. اضغط Commit to main ثم Push origin.
6. بعد اكتمال النشر افتح الموقع واضغط Ctrl + F5.
